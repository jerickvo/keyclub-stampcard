# Keystamp Mono

A ~100-glyph subset of DejaVu Sans Mono (Book), renamed so it never
collides with a system copy. It carries the app's record-keeping
register: chapter numbers, card numbers, seal numbers, times and the
scan status line. Digits, basic Latin, space, slash, colon, middle dot,
hyphen, en dash, comma, period, percent, plus, question mark,
parentheses, at, underscore, multiplication sign, apostrophes, hash,
ampersand, exclamation.

DejaVu fonts are distributed under the Bitstream Vera licence plus the
DejaVu changes (public domain). The licence permits modification and
redistribution provided the reserved names "Bitstream Vera" and
"DejaVu" are not used for a derived font, which is why this file is
named Keystamp Mono. Copyright notices are kept in the name table.

Rebuild with tools-build-fonts.py after changing this file.
